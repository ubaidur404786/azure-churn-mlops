# Demo

`demo.gif` shows the whole project in 10 pictures, one every 4 seconds:

1. the resource group with every Azure resource
2. the Bicep deployment that created them
3. the Azure ML training job
4. the model in the Azure ML registry
5. a git push that runs CI in GitHub Actions
6. the Deploy workflow that updates the live app
7. a live `/predict` call over HTTPS
8. Application Insights
9. a KQL query on the logs
10. the real cost: €0.12

All pictures are real screenshots taken while the project was live (October 2026). The email address and the subscription ID are cut out.

The GIF is made from the screenshots in [docs/screenshots/](../screenshots/), not recorded live, so it has no voice.
